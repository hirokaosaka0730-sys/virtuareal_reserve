# Studio VirtuaReal 予約顧客管理

`index.html` をブラウザで開くと利用できます。予約メール・フォーム通知を貼り付けると、利用日、氏名、時間、プラン、金額、オプションを抽出して月間予約表に追加します。

- 表は日付を横方向、予約1〜予約3を縦方向に表示します。同じ日に複数件の予約があれば、空いている予約番号へ自動で配置します。
- 予約カードまたは空のセルを選ぶと、内容を確認・修正できます。
- データはこのブラウザに保存されます。定期的に「バックアップ」でJSONを保存してください。
- 「CSVを書き出す」で、Excelで開ける予約一覧を出力できます。

## アプリとして使う（PWA）

このフォルダをHTTPSで公開すると、ブラウザからインストールできるPWAとして利用できます。MacではSafariまたはChromeの「インストール」、iPhoneではSafariの共有メニューから「ホーム画面に追加」を選んでください。

`file://` で直接開く方法ではPWAのオフライン機能は有効になりません。予約データは、これまでと同じく各端末のブラウザ内に保存されます。
